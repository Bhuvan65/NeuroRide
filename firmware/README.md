# Firmware

ESP32-WROOM-32 code for NeuroRide. Coming in Stage 1.

Planned sketches:

- `eog_signal_test` — read the BioAmp EXG Pill on GPIO 34 and plot it
- `gesture_detector` — double blink, glance left/right, jaw clench
- `motor_control` — TB6612 driver, forward/back/turn/stop
- `neuroride_main` — full system with safety, health and emergency features
